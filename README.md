# Automatização de Preenchimento de Formulários a partir de PDFs e API pública

Projeto em Python para automatizar um fluxo repetitivo de preenchimentos de formulários internos
extraindo dados de documentos PDF e complementando informações via API de consulta de CNPJ.

## Visão Geral

Este sistema automatiza um processo manual que envolvia:

- Leitura de documentos PDF contendo dados
- Extração estruturada via expressões regulares
- Enriquecimento de dados via API pública de CNPJ
- Preenchimento automático de formulários web e PDF usando **Selenium**

O objetivo foi reduzir tempo operacional e minimizar erros humanos.

## Funcionalidade
- Interface gráfica 
- Extração de campos relevantes diretamente de PDFs
- Validação de normalização dos dados extraídos
- Consulta automatizada de informações via API de CNPJ
- Preenchimento end-to-end de formulários web e pdf com Selenium
- Logs e tratamento de exceções para robustez

## Tecnologias
- Python 3
- Selenium WebDriver
- Regex parsing
- Requests
- Tkinter
- Pyautogui

## Observações

Este repositório contém uma versão anonimizada do projeto, sem dados sensíveis ou integrações específicas do ambiente corporativo.
Portanto o uso não será possível.
